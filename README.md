# Esporte Total – Website Institucional e E-commerce (Projeto Acadêmico)

Este projeto foi desenvolvido como **trabalho acadêmico em grupo** na graduação em Ciência da Computação, com o objetivo de aplicar na prática os conceitos de **desenvolvimento web** vistos em aula.

O sistema simula o site de uma empresa do ramo esportivo, contendo páginas institucionais, catálogo de produtos e funcionalidades típicas de um e-commerce.

## 🧠 Objetivo do projeto

Criar um website completo, estruturado e responsivo, simulando um sistema real de empresa, integrando **frontend e backend**, com foco em organização, navegação e experiência do usuário.

## 🧩 Funcionalidades implementadas

- 🏠 Página inicial (Home)
- ℹ️ Página institucional (Sobre)
- 🛍️ Catálogo de produtos
- 🆕 Página de novidades
- 📞 Página de contato
- 👤 Área do usuário (Minha Conta)
- ⭐ Sistema de favoritos (usuário logado)
- 🛒 Carrinho de compras
- ➕ Inserção de novos produtos (usuário logado)
- 🖼️ Upload de imagens de produtos
- 📱 Versão responsiva para dispositivos móveis
- 🔻 Rodapé com informações gerais

O projeto contempla fluxos diferentes para usuários **logados e não logados**, simulando regras básicas de acesso.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- Estruturação de páginas e componentes
- Conceitos básicos de backend e lógica de negócio
- Responsividade (desktop e mobile)

## 👥 Trabalho em grupo

Este projeto foi desenvolvido em grupo como parte da avaliação final da disciplina de Desenvolvimento Web.

**Minha contribuição no projeto incluiu:**
- Desenvolvimento de páginas em HTML e CSS
- Implementação de interações em JavaScript
- Participação na lógica de navegação e organização do site
- Colaboração na estrutura geral do sistema e fluxo de usuário

> Por se tratar de um projeto acadêmico, o foco foi o aprendizado prático e a aplicação dos conceitos estudados em sala de aula.
